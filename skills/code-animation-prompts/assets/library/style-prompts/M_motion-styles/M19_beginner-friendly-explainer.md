# M19 Beginner-Friendly Explainer

- Category: M Motion Styles · Explainers
- Looks like: Any art style; what matters is the way of explaining: start from an everyday example and build step by step up to the technical terms.
- Best for: A whole episode of the science-explainer track, or the "first explain what X is" section of the Feeling track.

## Style prompt

Make a video explaining [topic], going deep in plain language so that someone with no background can understand it. Open with an everyday example, then give the technical explanation. Include sound, with narration in the user's language. Install whatever tools you need, and you may search the web for reference.
