# Contributing and adding stills

You are welcome to add reference images for existing styles, fix the index, or contribute working code animations. Check the ID first to avoid duplicating a still. There is no need to rewrite existing style prompts.

## Reference images

- Use 1920x1080 at 16:9 where possible, and name the file after its prompt, for example `K1_flat-vector-character.jpg`. Prefer a clean picture as the default preview and put the name, feature notes and palette in the accompanying notes, so the style stays recognizable as a thumbnail.
- Keep each image focused on one style, and use the same scene when comparing several styles. The existing K1-K3 are preserved as the first community reference cards; they are not a layout you must follow.
- For code-generated images, include SVG, HTML or the generating script where possible, and describe the render method, size, fonts and dependencies. If you only have a JPG, say so plainly and do not claim to provide editable source.
- State the author, the source and the applicable license or sharing terms. For original submissions, state whether you agree to the repository's terms of free use, modification and sharing. Third-party works keep their own licenses and credits. Do not declare unverified material as original or label it all as MIT.

## Sources and index

1. `docs/source-manifest.json` is a fixed baseline. Never overwrite its hashes to make validation pass.
2. Register added files or deliberate changes in `skills/code-animation-prompts/references/library-changes.json`: current SHA-256, reason and contribution record. Changes to an existing file must also keep an `original_sha256` that matches the baseline.
3. Add the author and source to the skill's `references/attribution.md`, so installed copies keep the credit. The library `README.md` retains its count of 193 stills as a historical statement; do not update that number.
4. Update `skills/code-animation-prompts/assets/library/style-picker.html` and `_stats.json`, then run `python scripts/build_catalog.py`. Sync README, SKILL and any affected display images, not just the generation scripts.

## Checks before submitting

```bash
python scripts/validate_repo.py
python skills/code-animation-prompts/scripts/styles.py search ink --limit 3
python skills/code-animation-prompts/scripts/styles.py show K1
```

Check that new images load, enlarge and filter in the picker. Attach previews to your PR and list your verification results.

README images are generated by `scripts/build_visuals.py`, which reads counts from the catalog automatically. With Playwright installed, run:

```bash
python scripts/build_visuals.py --browser-channel chrome --skip-video
```

This uses your local Chrome, refreshes the PNGs and keeps the unchanged GIF. Without a browser channel it uses Playwright's Chromium. To rebuild the GIF, drop `--skip-video` and make sure FFmpeg is available.
